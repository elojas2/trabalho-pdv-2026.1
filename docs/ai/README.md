# docs/ai

Diretório exigido pelo enunciado para o registro do uso de IA.

- [`AI-LOG.md`](AI-LOG.md) — registro das interações relevantes com IA.
- [`transcricoes/`](transcricoes/) — conversas completas, prompts, configurações
  de agentes e versões iniciais (pré-revisão) de código/testes gerados por IA.

Convenção de nomes em `transcricoes/`:

```
AI-001-<assunto>.md              # conversa completa
AI-001-v0-<Classe>Test.java      # solução original da IA, antes da revisão
AI-001-config.md                 # instruções/ferramentas/configuração do agente
```
